# Query live Judgment data

- Use Judgment MCP for live Issues, traces, labels, and test runs.
- Call `discover_schema` before `sql_query`. Query traces with SQL.
- Use `search_docs` and `read_doc_page` for product and SDK how-to.
- Sign in with OAuth. Keep credentials out of chat. Read a tool's arguments on the MCP tools page when you need them.

## Start here

- [Connect coding agent](https://docs.judgmentlabs.ai/documentation/connect/connect-your-coding-agent)
- [MCP tools](https://docs.judgmentlabs.ai/documentation/reference/mcp-tools)
- [Query with SQL](https://docs.judgmentlabs.ai/documentation/agents/query-with-sql)
- [SQL schema](https://docs.judgmentlabs.ai/documentation/reference/sql-schema)

For live data, use Judgment MCP tools. For procedures the server already ships, call `get_skill`.
